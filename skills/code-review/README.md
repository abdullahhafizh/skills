# code-review

Evaluates git diffs, merge requests (MR), and pull requests (PR) for Spring Boot (Java) backend and Angular 20 (NgRx) frontend repositories against Jira acceptance criteria, quality gates, and 38 path-matched rule files.

```bash
npx skills add abdullahhafizh/skills --skill code-review
```

Outputs severity-graded line findings, rereview thread replies, and an Approve or Request changes decision.
