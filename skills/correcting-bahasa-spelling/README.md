# correcting-bahasa-spelling

Corrects Indonesian spelling against EYD V (EYD Edisi V). Use for cek ejaan, proofreading bahasa Indonesia, huruf kapital, huruf miring, typo, di/ke/dari, partikel pun, singkatan, angka, tanda baca, pemenggalan kata, or serapan. Not KBBI, grammar, or code.

```
npx skills add abdullahhafizh/skills --skill correcting-bahasa-spelling
```
