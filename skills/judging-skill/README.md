# judging-skill

Scores one Agent Skill against an eight-dimension rubric (120 points) and returns a grade, evidence quotes, and concrete edits. Use when scoring one SKILL.md, grading one skill package, or deciding whether that draft is worth keeping.

```
npx skills add abdullahhafizh/skills --skill judging-skill
```

One pass scores one skill. The rubric and the failure names live in `references/`.
