# code-precheck

Pre-checks Spring Boot (Java) and Angular 20 (NgRx) code changes against quality gates, Acceptance Criteria (AC), and unit testing standards before pushing or opening a merge request (MR) or pull request (PR).

```bash
npx skills add abdullahhafizh/skills --skill code-precheck
```

Ensures every code change qualifies for an immediate Approve decision by eliminating defects across Security, Performance, Architecture, and Testing pillars.
